# Business-Analyst-Portfolio
Business analysis portfolio - BRD, process mapping, cost-benefit analysis, UAT design, risk register, and KPI reporting for PaySmart, a digital payment platform for Nigeria's informal traders.

## 🛠️ Tools & Technologies

- **Google Docs** — requirements documentation, business cases building, process narratives, risk and test case tables
- **Microsoft Excel** — cost-benefit model, ROI and payback period calculations, visualisation
- **Miro** — AS-IS/TO-BE process mapping
- **Google Meet** — Stakeholder meeting, technical team meeting, elicitation
- **Powerpoint** — Presentation to stakeholders
- **Power BI** — data cleaning, visualization, dashboard design
- **GitHub** — version control and portfolio publishing

## 📐 Methodologies

- Stakeholder analysis & power/interest mapping
- MoSCoW prioritization
- Current/future state process mapping
- 5 Whys root cause analysis
- TIMWOODS waste analysis (Lean)
- Cost-benefit analysis, ROI & payback period modeling
- User Acceptance Testing (UAT) test case design
- Risk identification, mitigation, and contingency planning
- KPI definition and RAG-status scorecard reporting
